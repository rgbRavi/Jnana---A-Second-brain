## What's Working
- Background-safe chat state: in-flight replies, versions, flush before switch.
- Composer menus share one MenuRow vocabulary; armed Focused changes the Send label ("Quiz me").
- Quiz/analysis cards: semantic fieldset/legend, aria-live reveals, graded attempts never lost.

## Priority Issues
1. [P1] Assistant replies not rendered as markdown (FreeChat.tsx:1112 pre-wrap) — render via MarkdownLite.
2. [P1] Invisible mode precedence (Focused > Agent > Deep research; project/styles ignored in Agent/Focused) — single active-mode line, mutually exclusive modes or disabled rows with reasons.
3. [P1] Message actions right-click only; hover-only submenu; hand-rolled menu without Escape/arrow keys — visible "⋯" per message using ui/ContextMenu.
4. [P2] Convention breaks: native ask()/select, #fff/#e5484d, unconfirmed header delete — showConfirmDialog, SettingSelect, --on-accent/--danger.
5. [P2] Stale, non-teaching empty state — 3 starters (Quiz this week's notes / Ask my notes / Just chat).
6. [P2] Visual layer contradicts calm — drop mesh bg, glows, gradient bubble, glass.

## Persona Red Flags
- First-time student: "Focused" doesn't say "study my notes"; Source bar implies plain chat reads notes; quiz is 3 steps across two panels; raw markdown replies.
- Keyboard power user: no shortcuts; menus lack arrow nav; Fork/Edit need mouse.
- Screen-reader user: no live region for streaming/errors; div-onClick project cards; small text-3 hints (~3.5:1).
